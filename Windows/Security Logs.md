## Device Guard

### Device Guard Configuration Commands
| Command | Purpose |
|---------|---------|
| `(Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard).SecurityServicesConfigured` | Check within OS which Device Guard services are configured |
| `(Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard).SecurityServicesRunning` | Check within OS which Device Guard services are running |
| `DG-Readiness-Tool` | Run DGReadiness Tool and check if Credential Guard is Running |

### Device Guard Logs
| Security | Logs | ID | Description |
