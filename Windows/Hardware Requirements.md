# Hardware Requirements

| **Area** | **Customer Requirements** |
|----------|---------------------------|
| CPU | Minimum requirement is 1,6 GHz or faster x64-bit 2-core processor. |
| RAM | Minimum requirement is 8 GB RAM (64-bit). Computers that have lower RAM needs to be replaced or upgraded. |
| Disk Drive | Minimum 120 GB disk. Microsoft recommends at least 10% free disk space for Windows updates. |
| Graphics | 1280 x 768 screen resolution or better. DirectX 9 graphics processor with Windows Display Driver Model (WDDM) 1.0 or higher driver |
| .NET version | If required .Net 3.5 can be installed (optional) if there is dependencies on an application level. |
| External disk | Recommendation to utilize USB-C. |

# Features

| **Feature** | **Requirement** |
|-------------|-----------------|
| Secure Boot | Secure boot requires firmware that supports UEFI v2.3.1 Errata B and has the Microsoft Windows Certification Authority in the UEFI signature database. Secure Boot will be a requirement in the Windows 10 Compliance Policy. |
| BitLocker | Trusted Platform Module TPM 2.0 (TPM 2.0 is a requirement for Windows 10 Autopilot and Windows 11) |
| Windows Hello for Business | Windows Hello requires specialized illuminated infrared camera for facial recognition or iris detection, or a fingerprint reader which supports the Window Biometric Framework. Otherwise PIN can be used. |
| Exploit Guard & Application Control | Current UEFI firmware, Secure Boot, TPM 2.0 and support for Virtualization-based security (VBS) |
