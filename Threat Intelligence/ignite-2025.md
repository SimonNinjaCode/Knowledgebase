| Subject | Product(s) | Status | Additional Information |
| :--- | :--- | :--- | :--- |
| **1. Centralized Control Plane for AI Agent Governance** | **Microsoft Agent 365** | Available (Frontier program) | Extends the existing infrastructure for managing users to govern AI agents responsibly and at scale. Integrates leading security solutions: Microsoft Defender, Microsoft Entra, and Microsoft Purview to protect agents. Provides a **Registry** for a complete view of all agents, including unauthorized "shadow agents," supporting access control. |
| **2. Secure Identity and Access for AI Agents** | **Microsoft Entra Agent ID** | Preview (via Agent 365) | Offers an enterprise-grade solution for preventing agent sprawl by assigning unique, verifiable identities to agents. Enforces lifecycle governance and IT-defined guardrails for both agents and their creators. Protects agent access to resources, enabling conditional access and traffic inspection to reduce breach risks. |
| **3. Real-Time Data Loss Prevention for AI Prompts** | **Microsoft Purview DLP for Copilot prompts** | Preview | Automatically blocks Copilot and agents from responding if a prompt includes confidential data, such as credit card numbers or personal details. Mitigates data leakage risk by preventing sensitive information from being used for grounding in Microsoft 365 or web searches. This is a crucial control for securely deploying AI in daily workflows. |
| **4. Executive-Level AI Risk Oversight** | **Security Dashboard for AI** | Preview | A new, unified dashboard designed for **Chief Information Security Officers (CISOs)** and AI risk leaders. Aggregates real-time risk signals from Microsoft Defender, Purview, and Entra for unified visibility across AI assets. Accelerates AI risk mitigation by providing actionable, AI-powered recommendations and Security Copilot skills. |
| **5. Proactive Mid-Attack Threat Containment** | **Microsoft Defender (Predictive Shielding)** | Preview | A component of automatic attack disruption that uses threat intelligence to anticipate where attackers are likely to pivot. Proactively hardens pathways to critical assets by applying targeted, just-in-time actions (like Group Policy Object changes). This coordinated response reduces tens of thousands of potential attack paths to just a few, minimizing risk while optimizing business continuity. |
| **6. AI-Powered Security Management Agents** | **Security Copilot Agents (in Defender, Entra, Purview, Intune)** | Preview | Twelve new agents are embedded into workflows to streamline high-volume security tasks for SOC, Identity, Data Security, and IT teams. Agents automate tasks like alert triage (Defender), managing risky users (Entra), and remediating sensitive data exposure (Purview). Security Copilot is rolling out to all Microsoft 365 E5 customers, starting with Frontier customers. |
| **7. Unified Multicloud Security Posture Management** | **Microsoft Defender for Cloud (MDC)** | Preview | Integrates MDC deeply into the Defender portal, eliminating siloed tools across hybrid and multicloud environments. Provides a centralized asset inventory consolidated across Azure, AWS, and Google Cloud. Unifies posture management and threat protection in one dashboard, enabling security teams to see and act on threats from a single location. |
| **8. Browser Controls for Data Leak Prevention** | **Edge for Business Watermarking and Clipboard Controls** | Preview (later this month) | Watermarking overlays appear on sensitive files and sites based on sensitivity labels or DLP policies, serving as a visual reminder to users. **Protected clipboard** enables admins to define trusted boundaries for copy/paste actions, preventing data from leaving managed web apps. These features provide greater precision to guide user behavior and reduce risk without slowing productivity. |
| **9. Advanced Endpoint Protection in the OS** | **Windows 11 / Windows Server 2025 Security Updates** | Generally Available | Includes built-in **Sysmon functionality** for streamlined security event logging and reduced operational overhead. Organizations can use the **Post Quantum Cryptography (PQC) API** to secure algorithms against future quantum attacks. **Zero Trust DNS** enforces encrypted, policy-driven name resolution, aligning with NIST guidelines for network protection. |
| **10. Security and Governance for AI Development** | **Foundry Control Plane** | Preview | Extends Agent 365 for developers, providing unified visibility, security, and control over agents operating in the Microsoft Cloud. Built on Entra Agent ID, with Defender securing runtime activity and Purview protecting data flow, to help developers operate safe AI systems at scale. Enables real-time tracing, continuous monitoring, and policy enforcement (behavioral guardrails) for agent inputs and outputs. |
