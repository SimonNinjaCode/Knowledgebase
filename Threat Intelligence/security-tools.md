# Offensive Security Tools

A curated list of useful tools for security research, analysis, and offensive testing.

---

### AAD & Entra ID Tools

- [**AADInternals**](https://aadinternals.com/aadinternals/) – Deep Entra ID research & attack framework
- [**AADInternalsEndpoints**](https://github.com/Gerenios/AADInternals-Endpoints) – List of endpoints related to AADInternals
- [**GraphRunner**](https://github.com/dafthack/GraphRunner) – PowerShell toolkit for Microsoft Graph API exploitation
- [**msInvader**](https://github.com/mvelazc0/msInvader) – Microsoft 365 post-exploitation tool
- [**Pytune**](https://github.com/secureworks/pytune) – Post-exploitation tool for enrolling a fake device into Intune
