# 🛡️ Digital Defense Report 2024

## 📊 Cybersecurity Signals Analyzed

- **2023**: 65 trillion signals analyzed  
- **2024**: 78 trillion signals analyzed

---

## 🔥 Evolving Cybercrime & Nation-State Actors

- Cybercrime now uses a full spectrum of tools and techniques, previously unique to nation-state actors.
- Nation-state actors are more sophisticated, targeting:
  - Major technology providers
  - Enterprise supply chains
- **Defense strategies** should focus on:
  - Technique-layer protection
  - Multi-factor authentication (MFA)
  - Phishing-resistant MFA
  - XDR, device compliance
  - Attack surface reduction rules

### Targeted Sectors

- IT: 24%
- Education & Research: 21%
- Government: 12%

---

## ⚔️ Hybrid Warfare – Ukraine 🇺🇦

- **FSB-affiliated Russian actor** used:
  - ShortCut file + obfuscated PowerShell script
  - Goal: steal file types and spread malware via USB (wormable)
- **Torrent-based campaign** used pirated Microsoft software to gain initial footholds in Ukrainian networks

## 🌐 Cyber Threat Landscape

### 🔐 Identity Attacks – Password Spray & Phishing

- 600 million identity-based attacks per day target Microsoft customers
- **99%** of these attacks are password-based

---

## Ransomware

- **2.75×** increase in human-operated ransomware encounters
- **3×** decrease in ransomware attacks that reach encryption
- Common attack flow:
  > Helpdesk ➜ Social Engineering ➜ Password Reset ➜ MFA Reset

## 🖥️ Endpoint Security – Tampering

**176,000 incidents** involving Defender and security product tampering:

- Registry modifications
- `Nsudo` (Defeat Defender)
- Defender Control
- Configure Defender
- ToggleDefender

### Actionable Insights

- Enable **Tamper Protection**
- Configure **“Disable Local Admin Merge”** in Defender AV
- React **immediately** to tampering alerts

- QR code phishing: 25%
- Phishing attachments: 19%

### Post-Compromise BEC Behavior

- Inbox rule manipulation: 40%
- Lateral phishing: 25%
- Conversation hijacking: 25%
- MFA tampering: 10%

## 🇸🇪 Cyber POV: Sweden

### Church of Sweden Targeted (Blackcat RaaS)

- **Actor:** Blackcat (🇷🇺 RaaS operator)
- Systems encrypted, data exfiltrated
- Follow-up threats: Lockbit leaked **2.3M files**
- Recovery: **2 months**, thanks to strong cloud-based resilience

### Key Lessons

- **24/7/365** monitoring is critical
- Patching window has shrunk:
  - From **14–30 days** (5 years ago)
  - To **24–72 hours** today
