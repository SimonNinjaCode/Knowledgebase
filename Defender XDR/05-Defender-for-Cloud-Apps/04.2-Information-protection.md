# Information Protection Capabilities

## Discover, classify, label, and protect regulated and sensitive data stored in the cloud

| **Capability**                | **Recommendation**                                                                                          |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Sensitivity Labels**        | Use Microsoft Purview Information Protection to classify and label data using built-in or custom policies.  |
| **Auto-labeling Policies**    | Enable auto-labeling for SharePoint, OneDrive, and Exchange to automatically classify based on content.     |
| **Data Classification**       | Leverage Purview Data Classification to identify sensitive data across M365 workloads and third-party apps. |
| **Shadow IT Discovery**       | Enable App Discovery in Defender for Cloud Apps via endpoint telemetry to identify unsanctioned apps.       |
| **Sanctioning/Blocking Apps** | Use Defender for Cloud Apps to tag applications as sanctioned/unsanctioned based on risk and compliance.    |

***

## Enforce DLP and compliance policies for data stored in the cloud

| **Capability**                              | **Recommendation**                                                                                                                    |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Microsoft Purview DLP**                   | Deploy DLP policies across Exchange, SharePoint, OneDrive, Teams, and endpoints.                                                      |
| **Cloud App DLP**                           | Integrate Defender for Cloud Apps to monitor and control sensitive data in third-party SaaS apps.                                     |
| **File Policies (Defender for Cloud Apps)** | Create file policies to detect sensitive content (e.g., PII, health data) and apply actions: quarantine, remove sharing, notify user. |
| **Alerts & Governance**                     | Enable alerting and automated governance actions (e.g., file quarantine, remove external access).                                     |

***

## Information Protection Integration

*   **Settings > Cloud Apps > Microsoft Information Protection**

***

## File Inspection Capabilities

*   **Settings > Cloud Apps > Information Protection > Files**
*   **Settings > Cloud Apps > App Connectors > Microsoft 365**
    *   Edit Settings > Microsoft 365 Files

***

## Limit exposure of shared data and enforce collaboration policies

| **Capability**                        | **Recommendation**                                                                                                                                                                                              |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Activity Policies (MDA)**           | Monitor risky behaviors like mass external sharing or sensitive file sharing, especially in third-party apps.                                                                                                   |
| **OAuth App Control**                 | Set policies to detect and revoke high-permission OAuth apps that could access sensitive data.                                                                                                                  |
| **Session Policies**                  | Use Session Control with Entra Conditional Access to: <br> - Block downloads on unmanaged devices <br> - Apply DLP to uploads/downloads <br> - Restrict access to sensitive apps like Salesforce and ServiceNow |
| **Defender for Endpoint Integration** | Enable active mode to unlock remediation actions like quarantine; if in passive mode, rely on alerting and manual investigation.                                                                                |
| **Conditional Access Integration**    | Settings > Cloud Apps > App Connectors                                                                                                                                                                          |
