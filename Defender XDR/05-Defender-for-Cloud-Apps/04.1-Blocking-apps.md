# Blocking Third-Party Cloud Apps via Defender for Endpoint & Defender for Cloud Apps

Restrict access to third-party cloud applications using the integration between **Defender for Endpoint** and **Defender for Cloud Apps**.  
This is done using **unsanctioning** in Defender for Cloud Apps and blocking the URL as an **Indicator**.

---

## Overview

- Integrations for Defender for Endpoint & Defender for Cloud Apps  
- Unsanction cloud applications in Microsoft 365 Defender  
- Admin experience – Indicator & Example Alert for Microsoft 365 Defender  
- User experience – Windows enforces the block using SmartScreen or Exploit Guard depending on the browser used  

---

## Requirements

### License Requirements

- **Defender for Endpoint Plan 2** (required for MDE & MDA integration)

### Advanced Features in Defender for Endpoint

- Custom network indicators  
- Defender for Cloud Apps integration  

### Integrations in Defender for Cloud Apps

- Defender for Endpoint (used to enforce blocking of unsanctioned apps)

### Device Requirements

- For **Windows**: Ensure [Network Protection](https://learn.microsoft.com/en-us/microsoft-365/security/defender-endpoint/network-protection?view=o365-worldwide) is configured in **block mode**  
- For **iOS/iPadOS & Android**: Microsoft Defender must be deployed and configured to enforce the network block  

---

## Integration of Defender for Endpoint & Defender for Cloud Apps

With Indicators in Defender for Endpoint, we can block the following types of IoCs:

- File hashes  
- IP addresses  
- URLs/Domains  
- Certificates  

These can be added manually or triggered from an incident in Microsoft 365 Defender.  
In this scenario, we use the integration to **unsanction** a cloud app in Defender for Cloud Apps, which automatically:

1. Tags the app as unsanctioned  
2. Adds associated **URLs/Domains** to the Indicators list  
3. Enforces access restrictions on both Windows and mobile devices—if all requirements are fulfilled  

---

**Path:**  
`Defender XDR > Settings > Endpoints > Indicators > URLs/Domains`
