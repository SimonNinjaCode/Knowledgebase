# Security Operations Schedule

## Document Information

| Item | Details |
|------|---------|
| **Document Type** | Security Operations |
| **Purpose** | Unified operational task schedule for Defender XDR across all products |
| **Frequency** | Daily, Weekly, Monthly, Periodic |
| **Intended Audience** | Security Operations Center (SOC), Defenders |
| **Last Updated** | November 30, 2025 |

---

## Executive Summary

This document provides a consolidated operational task schedule for security teams managing Microsoft Defender XDR across all product lines (Endpoint, Identity, Office 365, Cloud Apps). The schedule is organized by frequency (daily, weekly, monthly, periodic) to ensure consistent operational coverage and threat response.

---

## DAILY OPERATIONS

### Defender for Endpoint (MDE)

| Task | Description | Location | Frequency |
|------|-------------|----------|-----------|
| **Monitor Incidents Queue** | Review new high-severity incidents generated by MDE | Microsoft 365 Defender > Incidents | Daily (start of shift) |
| **Review High-Impact Threats** | Examine threats with highest impact to organization from Threat Analytics | Threat & Vulnerability > Threat Analytics | Daily |
| **Triage & Assign Incidents** | Categorize incidents, assign to analysts, set priority | Incidents Queue | Daily |
| **Check EDR Sensor Health** | Verify Defender for Endpoint sensor reporting | Device Health > Sensor Health & OS Report | Daily |
| **Monitor Antivirus Health** | Check AV update status (platform, intelligence, engine) | Device Health > Microsoft Defender Antivirus | Daily |
| **Review Health Reports** | Check device health trends (AV signature, platform, EDR sensor) | Device Health Reports | Daily |
| **Review Action Center** | Monitor pending and completed remediation actions | Action Center | Daily |
| **Manage False Positives** | Identify and suppress known false positive alerts | Alerts > Suppression | Daily |

### Defender for Identity (MDI)

| Task | Description | Location | Frequency |
|------|-------------|----------|-----------|
| **Alert Triage & Investigation** | Review and triage daily alert queue | Microsoft 365 Defender > Alerts | Daily (start of shift) |
| **Investigate Suspicious Users** | Identify and investigate suspicious user activities | User Investigation Priority | Daily |
| **Monitor Secure Score** | Track identity security posture score | Secure Score | Daily |
| **Check Sensor Health** | Verify MDI sensor connectivity and health | Health Issues | Daily |
| **Review Domain Configuration** | Confirm domain sensor configuration remains intact | Sensor Management | Daily |

### Defender for Office 365 (MDO)

| Task | Description | Location | Frequency |
|------|-------------|----------|-----------|
| **Triage Email Alerts** | Review and triage email security alerts | Microsoft 365 Defender > Alerts | Daily (start of shift) |
| **Monitor Quarantine** | Review items in the quarantine queue for validation | Quarantine | Daily |
| **Review Threat Explorer** | Examine recent email threats and campaigns | Threat Explorer | Daily |
| **Safe Attachments Policy Review** | Verify policy is enforcing correctly | Policies & Rules > Safe Attachments | Daily |
| **Anti-Phishing Policy Audit** | Check anti-phishing policy effectiveness | Policies & Rules > Anti-phishing | Daily |

### Defender for Cloud Apps (MDCA)

| Task | Description | Location | Frequency |

## Troubleshooting Procedures

### Defender for Endpoint (MDE)

| Issue | Resolution Steps | Documentation |
|-------|-----------------|----------------|
| Missing incidents | Verify product licensed and configured | [Troubleshoot onboarding](https://learn.microsoft.com/en-us/microsoft-365/security/defender-endpoint/troubleshoot-onboarding) |
| Delayed alerts | Check firewall/proxy, verify URL allowlist | [Network configuration](https://learn.microsoft.com/en-us/microsoft-365/security/defender-endpoint/configure-proxy-internet) |
| Sensor health issues | Run Client Analyzer, review troubleshooting guides | [Troubleshoot sensor state](https://learn.microsoft.com/en-us/microsoft-365/security/defender-endpoint/troubleshoot-sensor-state) |
| ASR rule conflicts | Audit ASR rules, check for false positives | [ASR troubleshooting](https://learn.microsoft.com/en-us/microsoft-365/security/defender-endpoint/asr-rules-troubleshoot) |
| Live Response failures | Verify permissions, check device connectivity | [Live Response FAQ](https://learn.microsoft.com/en-us/microsoft-365/security/defender-endpoint/live-response-faq) |

### Defender for Identity (MDI)

| Issue | Resolution Steps | Documentation |
|-------|-----------------|----------------|
| Sensor offline | Check network connectivity, gMSA permissions | [Troubleshoot sensor connectivity](https://learn.microsoft.com/en-us/microsoft-365/security/defender-identity/sensor-settings) |
| Missing alerts | Verify sensor deployment on domain controllers | [Sensor deployment](https://learn.microsoft.com/en-us/microsoft-365/security/defender-identity/deploy-defender-identity) |
| Configuration issues | Review MDI configuration requirements | [Configure-mdi.md](../Source/Defender%20for%20Identity/configure-mdi.md) |
| Integration problems | Verify XDR integration enabled in MDI | [Integration settings](https://learn.microsoft.com/en-us/microsoft-365/security/defender-identity/defender-settings) |

### Defender for Office 365 (MDO)

| Issue | Resolution Steps | Documentation |
|-------|-----------------|----------------|
| Delayed email scanning | Check service health, verify connectors | [Service health dashboard](https://admin.microsoft.com/servicehealth) |
| Safe Attachments not blocking | Verify policy assignment and scoping | [Safe Attachments policies](https://learn.microsoft.com/en-us/microsoft-365/security/office-365-security/safe-attachments) |
| Anti-phishing false positives | Adjust policy rules, update allow/block lists | [Anti-phishing policies](https://learn.microsoft.com/en-us/microsoft-365/security/office-365-security/set-up-anti-phishing-policies) |
| Configuration analyzer errors | Review configuration against best practices | [Configuration Analyzer](../Source/Defender%20for%20Office%20365/configuration-analyzer.md) |

### Defender for Cloud Apps (MDCA)

| Issue | Resolution Steps | Documentation |
|-------|-----------------|----------------|
| Cloud Discovery not detecting | Verify discovery source configuration | [Discovery sources](https://learn.microsoft.com/en-us/defender-cloud-apps/discovery-detect) |
| Anomaly detection false positives | Tune baseline and suppression rules | [Anomaly detection policies](https://learn.microsoft.com/en-us/defender-cloud-apps/anomaly-detection-policy) |
| OAuth app blocking not working | Verify app governance policy scope | [App governance](https://learn.microsoft.com/en-us/defender-cloud-apps/app-governance-overview) |
| Session control failures | Check proxy configuration and connectivity | [Session control deployment](https://learn.microsoft.com/en-us/defender-cloud-apps/proxy-deployment-aad) |

## Security Operations Metrics

### Incident Response Time

| Metric | Target | Priority |
|--------|--------|----------|
| Critical incident assignment time | < 5 minutes | High |
| High severity incident assignment | < 15 minutes | High |
| Medium severity incident response | < 1 hour | Medium |
| Low severity incident response | < 4 hours | Medium |

### Alert Management

| Metric | Target | Priority |
|--------|--------|----------|
| Alert triage time | < 30 minutes | High |
| False positive rate | < 5% | High |
| True positive confirmation | > 90% | High |
| False positive resolution | < 24 hours | High |

### System Health

| Metric | Target | Priority |
|--------|--------|----------|
| Sensor health > 95% | Target | High |
| Alert generation latency | < 1 minute | High |
| Investigation completion rate | > 80% | High |
| Remediation success rate | > 95% | High |
