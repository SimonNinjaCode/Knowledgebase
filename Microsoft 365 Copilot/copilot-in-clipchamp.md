# Ask questions &amp; get summaries of any video with Microsoft Copilot in the Clipchamp player | Microsoft Support

## Översikt

Copilot in Clipchamp — en del av Microsoft 365 E7. Se [Microsoft Learn](https://support.microsoft.com/office/0b531ea9-2d9d-4830-97e4-2c1b2b8ca31d) för full dokumentation.

## Innehåll

Microsoft Copilot in [Clipchamp] through the video player page, helps you to quickly and effectively catch up with videos in your organization. Whether you missed a meeting or are watching the latest townhall, product demo, or how-to video, Copilot can quickly summarize and answer questions for any video with a transcript.

## Get started with Copilot in Clipchamp

To use Copilot in Clipchamp through the player page, you need to have a Microsoft 365 Copilot license and the Microsoft 365 Copilot for SharePoint service plan.

1.  Go to [https:⁠//m365.cloud.microsoft/launch/Clipchamp/] to access the home page and then select the video to access it in the video player.  If the video doesn\'t have a transcript, you\'ll need to generate a transcript first.
2.  Look for Copilot on the right side of the video. In most cases where the screen size is large enough, Copilot opens by default. In cases where the window for the video is small, you may need to select the Copilot icon to open it.
3.  Select a suggested prompt in the Copilot box, such as \"Summarize the video.\"
4.  Copilot will return what you ask for and will show linked timestamps so you can jump to the spot in the video where the information or answer came from.
5.  To get more information about a video, ask Copilot in the prompt area. You can ask Copilot to help you understand anything from the video transcript including key topics, themes, trends, and open questions.

### Generate a transcript

Copilot in Clipchamp leverages the video transcript. If the video doesn\'t have a transcript, follow these steps:

1.  Navigate to **Edit** \> **Video Settings** \> **Transcript and Captions**.
2.  Select **Generate** to create a transcript.
3.  Soon after the transcript is generated, Copilot will be able to answer questions related to it.

If you don\'t have edit permissions, contact the video owner. For more information about transcripts and captions, see [View, edit, and manage video transcripts and captions].

## Using Copilot

Copilot is your personal video assistant that helps you get what you need from videos in seconds. You can ask Copilot a question about the video, and it will answer based on information in the transcript.

You can use Copilot in Clipchamp\'s video player to:

- Summarize any video to identify relevant points you need to watch.
- Ask questions to get insights from long or detailed videos.
- Locate where people, teams, or topics are discussed so you can jump to that point in the video.
- Identify calls to action and where you can get involved to help.

You can get started quickly by selecting a suggested prompt or type your question into the box for more specific information.

Copilot helps you maximize your work by quickly getting the information you need from videos. For example, if you\'re the project manager assigned to a new construction project, you might ask:

- What are the latest project updates and issues?
- Is this project running on time and on budget?
- Have any new risks been identified, and how are they being managed?
- Are there any challenges facing material distribution to the dispersed job sites?
- How does the site design accommodate hybrid work?

## Limitations

For Copilot to work in Clipchamp using the video player page, you need to have third-party cookies enabled. To learn more about allowing cookies in Microsoft Edge, see [Temporarily allow cookies and site data in Microsoft Edge.]

Copilot requires more than 100 words in the video transcript. If the transcript is too short, Copilot will not function.

Copilot will only be able to read the first transcript that is generated for the video. In a case where multiple transcripts or translations have been added to the video, Copilot will only be able to read the original transcript.
