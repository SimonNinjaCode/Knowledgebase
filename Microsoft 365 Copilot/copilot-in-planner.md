# Create a new plan with Copilot in Planner (preview) | Microsoft Support

## Översikt

Copilot in Planner — en del av Microsoft 365 E7. Se [Microsoft Learn](https://support.microsoft.com/planner/copilot/create-a-new-plan-with-copilot-in-planner-preview) för full dokumentation.

## Innehåll

Applies To

[Microsoft Planner]

Sebastian runs two neighborhood ice cream shops. In the early years of his business, he offered ten flavors, available in bowls, cones, and milkshakes. This year, he's planning to add sundaes to the menu but isn't sure how to approach the launch. Using Copilot in Planner (preview), he's able to outline a step-by-step plan to help organize the rollout.

To create a new product launch plan using Copilot in Planner (preview), Sebastian completes the following steps:

1.  Select **New plan**.

2.  In the **Create new** window, select **Premium**.

    ::: NOTE

    Copilot isn\'t available to use in basic plans.
    :::

3.  Enter a name for the new plan, select whether to pin the plan to the left navigation, and, optionally, choose a group to assign the plan to.

4.  Select **Create**.

5.  At the top right of the new plan, select **Copilot** [
    ![Copilot Icon]

    .

6.  In the compose box, enter, \"*Create a plan with buckets, goals, and tasks for adding sundaes to an existing ice cream shop\'s menu.⁠*\"

    ::: TIP
    Tip

    Enter **⁠/⁠** to open a dialog in which Copilot will suggest files or people to add to the prompt.
    :::

7.  Select **Send**[
    ![Teams chat send button icon]

    and Copilot creates buckets, tasks, and goals for launching sundaes as a new menu item.

With this plan outline, Sebastian has the flexibility to tailor the plan as needed. He can also use Copilot in Planner (preview) to help him add more tasks, revise goals, and edit buckets.
