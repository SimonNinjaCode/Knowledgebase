# FastTrack för Microsoft Copilot: säker utrullning

FastTrack ger fjärrvägledning för beredskap, licenstilldelning, inställningar,
agenter och rapportering. Det är vägledning, inte en data governance-
bedömning eller ett genomförandeprojekt.

## Säkerhetsrelevanta delar

- Granska licenstilldelning och förutsättningar.
- Åtgärda oversharing med SharePoint Advanced Management och Purview.
- Sätt Copilot- och agentinställningar i Microsoft 365 admin center.
- Använd Agent 365 där central agentstyrning behövs.
- Följ upp audit, data protection, access, ALM och rapportering.

FastTrack anger också vad som ligger utanför tjänsten, bland annat
projektledning, egna rapporter, data governance assessment och kundspecifik
agentutveckling. Lägg därför ett eget kontroll- och evidensspår bredvid
FastTrack-guidningen.

## Rekommenderad användning

1. Använd FastTrack för att förstå ordningen och Microsofts förutsättningar.
2. Gör en separat riskbedömning av behörigheter, data, identiteter och
   externa AI-tjänster.
3. Testa kontrollerna i tenantens egna scenarier innan bred tilldelning.
