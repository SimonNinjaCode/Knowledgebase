# SecOps - Operational Schedule

| **Daily Tasks** | **Weekly Tasks** | **Monthly Tasks** |
|-----------------|------------------|--------------------|
| **Incident Investigation**<br> Triage and [**investigate incidents**](https://learn.microsoft.com/en-us/azure/sentinel/tutorial-detect-threats-siem) generated by analytics rules and start investigating new ones based on prioritization. | **Analytic Rules**<br>Where applicable, renew and [**enable new analytics rules**](https://learn.microsoft.com/en-us/azure/sentinel/tutorial-detect-threats-custom) including new data sources or rules. | **User Access**<br>Review [**current permissions**](https://learn.microsoft.com/en-us/azure/sentinel/roles) and inactive users. Use least privilege. |
| **Workbook exploration**<br>Analyze visualized data using [**Sentinel Workbooks**](https://learn.microsoft.com/en-us/azure/sentinel/sentinel-workbooks). Use them for investigations, hunting, and insights. | **Data connectivity**<br>Ensure [**data connectors**](https://learn.microsoft.com/en-us/azure/sentinel/connect-data-sources) are healthy and that [**Log Analytics**](https://learn.microsoft.com/en-us/azure/azure-monitor/logs/log-analytics-overview) is connected. | **Log Analytics Review**<br>Review your [**Log Analytics Retention Policy**](https://learn.microsoft.com/en-us/azure/azure-monitor/logs/logs-data-retention-policy). Ensure it's aligned with org policy. |
| **Hunting Queries & Bookmarks**<br>Evaluate results for built-in and custom queries. | **Workbook updates**<br>Check if any workbooks [**need updates**](https://learn.microsoft.com/en-us/azure/sentinel/sentinel-workbooks) for new features. | **News & Updates for Sentinel**<br>Review [**new Sentinel features**](https://learn.microsoft.com/en-us/azure/sentinel/whats-new). |
| Manually generate incidents from results. | **Sentinel Auditing**<br>[**Review Sentinel auditing**](https://learn.microsoft.com/en-us/azure/sentinel/audit-logs). | **GitHub Repository**<br>Review content from the [**Sentinel GitHub Repository**](https://github.com/Azure/Azure-Sentinel). Use applicable content. |
