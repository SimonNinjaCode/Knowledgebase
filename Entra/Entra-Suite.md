# 🔐 Entra Suite Features

### Microsoft Entra Private Access
An identity-centric Zero Trust Network Access that secures access to private apps and resources while reducing operational complexity and replacing legacy VPNs.

### Microsoft Entra Internet Access
An identity-centric Secure Web Gateway (SWG) for SaaS apps and internet traffic. Protects against:
- Malicious traffic
- Unsafe or non-compliant content
- Open internet threats

### Microsoft Entra ID Governance
A complete identity governance and lifecycle automation solution ensuring the right people have the right access at the right time.

### Microsoft Entra ID Protection
Advanced threat detection and response for identity-based risks.

### Microsoft Entra Verified ID
A **verifiable credentials** service based on open standards.
